📚 WMK Book Studio — Roadmap

Projeto para criar, editar, ouvir e publicar livros digitais com foco em Windows offline. A legenda descreve implementação no código, não testes concluídos.

v0.1 • Primeira implementação ● Código enviado

  • Galeria de projetos, criação e edição de capítulos
  • Autosave local, importação/exportação JSON
  • Exportação HTML e impressão do livro em PDF
  • Leitor de textos com narração Web Speech API
  • Facebook, WhatsApp, Telegram, Web Share API
  • Interface pt-BR, identidade WMK, README
  • Empacotamento Tauri/Windows via GitHub Actions (a validar)

v0.2 • Designer visual ○ Planejado

  • Páginas A4/A5/A6 e personalizadas; margens, sangria e guias
  • Caixas de texto, imagens, formas, camadas, zoom/pan, grade e snap
  • Painéis móveis e layouts de workspace salvos em JSON
  • Capas, templates e biblioteca de elementos visuais
  • Desfazer/refazer com histórico confiável

v0.3 • Publicação editorial ○ Planejado

  • EPUB 3 válido, sumário navegável e metadados
  • PDF completo com paginação, cabeçalho e rodapé
  • Gerenciamento de fontes, imagens, revisão e acessibilidade

v0.4 • Assistentes de IA ○ Planejado

  • Ollama offline e Groq/OpenAI opcionais online
  • Agentes escritor, revisor, ilustrador e diagramador
  • Versionamento, diff, custos e aprovação de mudanças

v1.0 • Editor profissional ○ Planejado

  • SQLite, backup seguro, recuperação e formatos de projeto
  • Publicação por link, redes sociais e QR Code
  • Instalador testado, testes automatizados e documentação completa
